响应式图片 srcset / sizes 怎么用？ ​

同一内容在不同视口宽度 / DPR 下应选用不同分辨率的图片，避免小屏拉大图、大屏糊图。HTML 用 srcset + sizes（或 <picture> 做艺术方向）描述候选。

一、w 与 x：两种场景 ​

场景用啥一句话
同一张图，手机拉满屏、电脑只占一列 → 显示宽度随断点变w + sizes多准备几种不同像素宽度的同一内容图，让浏览器按「将要占多宽 × 屏幕倍数」挑一张合适的文件。
图标、头像框死成 比如 24×24 CSS 像素，只是 Retina 要更锐x（密度描述符）同一逻辑尺寸，提供 1 倍、2 倍、3 倍 文件；不需要 sizes。

用 w 时：两个数字分别是什么？ ​

  1. 480w 里的 480：指这张图片文件本身横向有多少像素（文件有多宽），不是「要在页面上显示多少」。
  2. sizes：告诉浏览器「这个 <img> 在页面上大概占多宽的 CSS」（例如窄屏占满屏 100vw，宽屏占半屏 50vw）。浏览器还没画完页面时就要决定选哪张图，所以靠 sizes 先估算。

大致逻辑（不用背公式）：浏览器会算「当前需要显示多宽 × 设备像素比（DPR）」，再在 srcset 里挑一张够清晰、又尽量不占带宽的图。

html
<!-- 例：文章配图。手机全宽；窗口 ≥600px 时，图只占内容区一半宽 -->
<img
  src="article-800.jpg"
  srcset="article-400.jpg 400w, article-800.jpg 800w, article-1200.jpg 1200w"
  sizes="(max-width: 599px) 100vw, 50vw"
  alt="文章配图"
/>
  • 若手机视口 360px，100vw≈360px，2x 屏大约需要 720 像素宽的素材 → 会倾向选 800w 那张。
  • 若桌面内容区 1200px、图占一半 → 约 600 CSS 宽 → 可能选 800w 或 1200w，由浏览器策略决定。

不写 sizes 时：浏览器往往默认按 100vw 去估，等于「整张图永远当全屏宽」，容易误选过大的图（浪费流量）。

用 x 时：和 w 差在哪？ ​

  • 1x / 2x / 3x：表示「相对基准密度」——通常对应 1 倍、2 倍、3 倍屏（Retina）。
  • 这类写法前提是：你在 CSS 里已经给了固定显示尺寸（例如 .icon { width: 24px; height: 24px; }），所以浏览器知道「逻辑上就是 24px 宽」，只需在几份不同像素尺寸的文件里选一份匹配 DPR。
html
<!-- 图标在 CSS 里写死 24×24，1x 文件 24px 宽，2x 文件 48px 宽 -->
<img
  class="icon"
  src="search-24.png"
  srcset="search-24.png 1x, search-48.png 2x"
  width="24"
  height="24"
  alt=""
/>
  • 不要在同一 srcset 里混用 w 和 x。
  • 内容区宽度随响应式一直变的横幅图，优先用 w + sizes，而不是一堆 x。

二、sizes 配合 w 使用 ​

  • sizes 只在 srcset 里用了 w 描述符时必不可少：它描述「不同断点下，这个 <img> 在布局里大概占多宽」。
  • src：老浏览器或无法解析 srcset 时的兜底。

三、picture 与 type ​

艺术方向（横竖裁切不同、不同构图）用 <picture> 多 <source>，媒体查询选源：

html
<picture>
  <source media="(min-width: 800px)" srcset="wide.jpg" />
  <source media="(max-width: 799px)" srcset="narrow.jpg" />
  <img src="fallback.jpg" alt="" />
</picture>

格式切换（WebP / AVIF）可用 type：

html
<picture>
  <source type="image/avif" srcset="a.avif" />
  <source type="image/webp" srcset="a.webp" />
  <img src="a.jpg" alt="" />
</picture>

四、面试小结 ​

  1. w = 每张文件有多宽；sizes = 页面上大概占多宽；两者配合才能选对。
  2. x = 显示尺寸固定，只换 1x/2x 清晰度；不用 sizes。
  3. sizes 写错 → w 列表会选错图。
  4. <picture>：裁切或格式不同；<img> + srcset + sizes：同一构图多分辨率。
  5. 与 图片懒加载 组合时，首屏大图慎用 lazy。
