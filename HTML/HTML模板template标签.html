HTML 模板 <template> 标签是什么？ ​

页面加载时，<template> 里的内容不会出现在页面上，也不会产生常规副作用：内部的 img 不会请求、script 不会执行（处于惰性 / inert 状态）。真实 DOM 树挂在 template.content 上，类型是 DocumentFragment。要用时再用 JS cloneNode(true) 克隆一份，插进文档，这时图片、脚本才会按正常规则加载和执行。

内部仍是合法 HTML，会被解析进 fragment；和「未解析的字符串」不是一回事。

一、和 display: none 的区别 ​

display: none<template>
是否在主 DOM 里在，只是不显示内容在 DocumentFragment 里，不插入主文档显示树
子资源元素已在文档中，img 往往会加载不请求（克隆进主文档前）
脚本已在文档中的 script 通常会执行不执行（惰性）
典型用途隐藏已存在的 UI存一段未插入主文档的静态片段，用时 cloneNode 再插入

一句话：display:none 隐藏已在文档中的节点；<template> 里的节点不插入主文档显示树，克隆前不加载子资源、不执行脚本。

二、和 innerHTML / 字符串模板 ​

<template>字符串拼 HTML
解析按 HTML 规则进 fragment，结构合法容易拼错标签、要防 XSS
显示默认不占版面一旦 innerHTML 插入即参与布局与加载

template.content 用 cloneNode(true) 深拷贝，再 appendChild 到目标容器。

三、典型用法 ​

表格行：

html
<template id="row">
  <tr>
    <td class="name"></td>
    <td class="value"></td>
  </tr>
</template>
js
const tpl = document.getElementById('row');
const tbody = document.querySelector('tbody');
const row = tpl.content.cloneNode(true);
row.querySelector('.name').textContent = 'A';
tbody.appendChild(row);

卡片：克隆后再改文案、再挂到 body：

js
const tmpl = document.querySelector('#card-template');
const clone = tmpl.content.cloneNode(true);
clone.querySelector('.title').textContent = '动态标题';
document.body.appendChild(clone);

列表行、弹窗、卡片骨架都适合用模板，避免长字符串拼接。与 图片懒加载 配合时：模板里的 img 在克隆前进主文档之前不会请求。

四、与 Web Components、框架 ​

  • <template> + Shadow DOM + Custom Elements 常被称为原生组件化的三件套：template 存结构，Shadow 隔离样式，自定义元素挂标签。
  • Vue / React 的模板编译（把模板变成可执行的渲染逻辑）也广泛从这种「声明式片段 + 运行时实例化」思路里借鉴。

<slot> 多在 Shadow DOM 里做内容投影；<template> 存的是可克隆的静态片段，职责不同。

五、面试小结 ​

  1. 惰性：不渲染、不加载子资源、不执行脚本；内容在 DocumentFragment。
  2. 实例化：template.content.cloneNode(true) 再插入文档。
  3. 和 display:none：后者隐藏已在文档中的节点；<template> 内容在 fragment 中，克隆前无加载与脚本副作用。
  4. WC 三件套 + 与 Vue/React 模板思路的关联可顺带提一句。
