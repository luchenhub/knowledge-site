data-* 自定义属性的使用场景与最佳实践？ ​

data-* 是 HTML5 规范中用于在元素上存储自定义私有数据的标准方式，不会影响元素的语义或表现，仅供 JavaScript 和 CSS 读取使用。

一、基本语法 ​

属性名必须以 data- 开头，后接自定义名称（小写字母、数字、连字符）：

html
<!-- 单个值 -->
<div data-id="123" data-name="hello"></div>

<!-- 布尔值：存在即为 true，JS 中通过 hasAttribute 或判断 dataset.active !== undefined -->
<button data-active></button>

<!-- JSON 对象（需手动序列化） -->
<div data-config='{"theme":"dark","lang":"zh"}'></div>

二、JavaScript 访问 ​

dataset API ​

通过 element.dataset 访问，属性名自动转换为驼峰命名：

html
<div data-user-id="42" data-user-name="Alice"></div>
js
const el = document.querySelector('div');

// 读取
el.dataset.userId    // "42"（字符串）
el.dataset.userName  // "Alice"

// 写入
el.dataset.role = 'admin'
// 生成: data-role="admin"

// 删除
delete el.dataset.userId

⚠️ dataset 返回的值始终是字符串，需手动转换类型。

getAttribute（兼容性更好） ​

js
el.getAttribute('data-user-id')  // "42"
el.setAttribute('data-user-id', '100')
el.removeAttribute('data-user-id')

dataset 与 getAttribute 的区别：

特性datasetgetAttribute
命名方式驼峰（data-user-id → userId）原始（data-user-id）
浏览器支持IE11+所有浏览器
读取速度略慢（需转换）略快

三、CSS 中使用 ​

通过 attr() 函数读取 data-* 值，常用于内容注入或条件样式：

css
/* 将 data-tooltip 的值作为提示文字 */
.tooltip::after {
  content: attr(data-tooltip);
  position: absolute;
  background: #333;
  color: #fff;
  padding: 4px 8px;
  border-radius: 4px;
}
html
<span class="tooltip" data-tooltip="点击查看详情">按钮</span>
css
/* 根据 data-* 值设置样式（CSS 属性选择器） */
[data-theme="dark"] {
  background: #1a1a1a;
  color: #fff;
}

[data-theme="light"] {
  background: #fff;
  color: #333;
}

💡 attr() 用于 content 等时，属性值来自 DOM；在现代浏览器中，用 JS 修改 data-* 后，依赖 attr() 的伪元素内容一般会随样式重算而更新。若需兼容极老浏览器，应以实测为准，重要 UI 不宜只依赖「改属性自动刷新伪元素」这一条路径。

四、常见使用场景 ​

1. 存储业务 ID ​

html
<li data-product-id="P1001" data-category="electronics">商品A</li>

点击事件中获取 ID，避免拼接字符串或使用隐藏字段：

js
list.addEventListener('click', (e) => {
  const productId = e.target.dataset.productId
  fetchProductDetail(productId)
})

2. 配置参数传递 ​

html
<button data-action="submit" data-form="login">登录</button>
js
document.addEventListener('click', (e) => {
  if (e.target.dataset.action === 'submit') {
    const formName = e.target.dataset.form
    submitForm(formName)
  }
})

3. 状态标记 ​

html
<button data-loading="true" disabled>提交中...</button>
css
[data-loading="true"] {
  opacity: 0.6;
  cursor: wait;
}

4. 列表/表格行操作 ​

html
<table>
  <tr data-row-id="1">
    <td>张三</td>
    <td><button data-action="delete">删除</button></td>
  </tr>
</table>

5. 组件初始化配置 ​

html
<div class="carousel" data-interval="3000" data-autoplay="true">
  <!-- 轮播内容 -->
</div>
js
document.querySelectorAll('.carousel').forEach(el => {
  new Carousel(el, {
    interval: Number(el.dataset.interval),
    autoplay: el.dataset.autoplay === 'true'
  })
})

五、最佳实践与注意事项 ​

✅ 推荐 ​

  • 仅存储页面私有数据；若只是主题色、间距等纯展示变量，优先 CSS 自定义属性；若状态既要给 JS 又要驱动样式（如 data-open、暗色开关），用 data-* + 属性选择器是常见做法
  • 命名使用连字符（data-user-id），JavaScript 中用驼峰读取
  • 布尔值用属性存在性判断，而非 data-active="true"
  • 复杂数据用 JSON 序列化，但注意转义引号

❌ 避免 ​

  • 不要用 data-* 存储敏感信息（如密码、Token），可通过 DevTools 轻松查看
  • 不要过度依赖，频繁读写 DOM 性能差，大量数据应存内存中
  • 不要把大量设计 token 塞进 data-*（冗长、难维护）；纯样式优先 CSS 变量，与上条一致
  • 不要替代语义化属性，如 role、aria-* 等

与其他方案对比 ​

方案适用场景缺点
data-*元素级私有数据，JS/CSS 读取敏感信息暴露
CSS 变量样式相关数据，主题配置JS 访问不便
class样式开关、状态标记数据存储能力弱
自定义属性（非 data-）不符合 HTML 规范验证工具会报错
内存变量大量/频繁访问的数据无法与 DOM 元素关联

六、小结：面试怎么答 ​

  1. data-* 是 HTML5 标准，用于在元素上存储自定义私有数据。
  2. JavaScript 通过 dataset 读写，属性名自动转驼峰；getAttribute 兼容性更好。
  3. CSS 通过 attr() 读取值，常用于动态内容注入；也可用属性选择器做条件样式。
  4. 常见场景：存储 ID、传递配置参数、标记状态、组件初始化配置。
  5. 注意点：值始终是字符串、勿存敏感信息、复杂数据用 JSON、样式相关用 CSS 变量。
