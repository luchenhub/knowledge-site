本地运行与部署 ​

本站使用 VitePress 构建，将 Markdown 笔记渲染为静态文档站。

bash
# 安装依赖
npm install

# 本地开发（热更新）
npm run docs:dev

# 构建静态站点（输出到 .vitepress/dist）
npm run docs:build

# 预览构建结果
npm run docs:preview

部署到 GitHub Pages 时，若站点放在仓库子路径（如 https://<user>.github.io/front-end/），需在 .vitepress/config.mts 中设置 base: '/front-end/'。

发布到另一个仓库（GitHub Pages 专用） ​

打包完成后执行 pnpm run publish 会把 dist 推送到你配置的另一个 Git 仓库（该仓库开通 GitHub Pages 即可对外访问）。

  1. 复制 .env.example 为 .env，填写 PUBLISH_REPO（必填）：
    • 示例：PUBLISH_REPO=git@github.com:你的用户名/你的用户名.github.io.git
    • 或项目站：PUBLISH_REPO=https://github.com/你的用户名/仓库名.git
  2. 可选：在 .env 中设置 PUBLISH_BRANCH，不填则默认推送到 gh-pages 分支。
  3. 在终端执行：
    bash
    pnpm run publish
    会先执行 docs:build 再推送 .vitepress/dist 到目标仓库对应分支。
